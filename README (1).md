# AquaBovine Nutrition
1. Open this folder in VS Code (File > Open Folder).
2. Terminal > New Terminal, then:
   - Windows: `python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`
   - Mac/Linux: `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`
3. `python app.py` (or press F5), wait for "Ready.", open http://127.0.0.1:5000
4. Click "Play demo tour" for the guided walkthrough.
Hardware: POST JSON to http://<PC-IP>:5000/api/ingest (see Hardware tab).
